# VK-group-synchronizer
## Скрипт для управления сообществами vk.com

Позволяет производить следующие типы операций с группами:
- Создание группы с описанием, аватаркой и ссылками
- Редактирование полей группы - описания, аватарки и ссылок
- Подписываться на все группы с определенного аккаунта и дать права админа этому аккаунту

Источником истины для скрипта служит google таблица, от туда он берет данные для работы с группами. Пример таблицы с данными:

|vk_id|updating|title  |description  |screen_name|avatar|
|-----|--------|-------|-------------|-----------|------|
|1    |FALSE   |title 1|description 1|-          |-     |
|2    |FALSE   |title 2|description 2|-          |-     |
|3    |FALSE   |title 3|description 3|-          |-     |
|4    |FALSE   |title 4|description 4|-          |-     |
|5    |FALSE   |title 5|description 5|-          |-     |
|6    |FALSE   |title 6|description 6|-          |-     |

Скрипт обработает только записи, где updating = TRUE. В данном случае TRUE или FALSE это логические константы гугл таблиц, там они выглядят так.
Перед запуском скрипта замените файл credentials.json на файл с вашим сервисным аккаунтом google. После этого переименуйте .env.example в .env и внесите туда свои данные. Все переменные описаны в комментариях в этом файле.
Скрипт читает только ячейки таблицы, в которых значение отличается от "-". Если не хотите обновлять какое-то поле, просто внесите туда "-".

## Запуск скрипта
Перед запуском создайте среду и установите зависимости:
```bash
python3 -m venv env
source ./env/bin/activate
python3 -m pip install -r requirements.txt
```

После подготовки можно запускать скрипт
```bash
python3 ./presentation/cli.py --help
```
